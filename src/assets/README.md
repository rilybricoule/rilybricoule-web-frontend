# Assets

This directory contains static assets like images, icons, and fonts.

## Structure

```
assets/
├── images/
│   ├── logo.png
│   ├── hero/
│   └── services/
├── icons/
│   └── *.svg
└── fonts/
    └── *.ttf
```

## Guidelines

- Optimize images before adding (use WebP when possible)
- Use SVG for icons and logos when possible
- Keep file sizes reasonable
- Organize by type (images, icons, fonts)
- Consider using public folder for static assets that don't need processing
